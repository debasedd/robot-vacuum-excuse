# The Robot Vacuum's Best Excuse

[![The Robot Vacuum's Best Excuse](https://make.fun/badge/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214.svg)](https://make.fun/c/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214)

A tiny program for [The Robot Vacuum's Best Excuse](https://make.fun/c/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — the funniest excuse a robot
vacuum could give for missing a spot:

> I mapped the crumb, approached with confidence, then my bumper signed a peace treaty with the chair leg instead.

Run it with:

```sh
python3 main.py
```
